# 🏦 Projeto ATM — Caixa Eletrônico

Sistema de **Caixa Eletrônico (ATM)** desenvolvido em linguagem C/C++ como projeto acadêmico, com o objetivo de aplicar na prática conceitos fundamentais de programação, organização de código, estruturas de dados e desenvolvimento de sistemas.

O projeto simula operações básicas realizadas em um caixa eletrônico, permitindo ao usuário acessar sua conta e executar diferentes operações bancárias através de um menu interativo.

---

## 📌 Sobre o Projeto

O **Projeto ATM** foi desenvolvido como uma aplicação de console que simula o funcionamento básico de um caixa eletrônico.

A aplicação possui módulos responsáveis por diferentes funcionalidades do sistema, permitindo organizar as operações de forma separada.

Entre as principais funcionalidades estão:

* 🔐 Login e acesso ao sistema
* 💰 Consulta de saldo
* 💵 Depósito
* 💸 Saque
* 📋 Histórico de operações
* 🖥️ Menu de navegação
* 💳 Controle das operações bancárias

O projeto foi desenvolvido com foco acadêmico e tem como objetivo fortalecer conhecimentos de programação e desenvolvimento de sistemas.

## ⚙️ Funcionalidades

### 🔐 Login

Permite que o usuário realize o acesso ao sistema antes de utilizar as funcionalidades do caixa eletrônico.

### 💰 Consulta de Saldo

Exibe o saldo disponível na conta do usuário.

### 💵 Depósito

Permite adicionar um determinado valor ao saldo da conta.

### 💸 Saque

Permite retirar um valor da conta, realizando a atualização do saldo.

### 📋 Histórico

Registra e permite consultar operações realizadas no sistema.

### 🖥️ Menu

Centraliza as funcionalidades disponíveis, permitindo que o usuário escolha qual operação deseja executar.
